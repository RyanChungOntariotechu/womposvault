# Womposvault
A Flask web app that aggregates live game giveaways, free games, in-game loot, and beta access opportunities using the GamerPower API. Users can browse active giveaways across 13+ platforms — including Steam, Epic Games Store, PlayStation, Xbox, Switch, GOG, and mobile — filtered by platform, giveaway type (game, loot, or beta), and sorted by value or popularity.

Each giveaway is displayed with its title, cover image, platform, estimated worth, and a direct link to claim it. The site features a dropdown-based filter menu grouped by platform category (PC/Store, Console, Mobile) plus type and sort options, all built with Flask, Jinja2 templating, and custom CSS.

Built with: Python, Flask, Jinja2, HTML/CSS, GamerPower REST API
